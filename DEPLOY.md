# 🚀 Get the site live for free (step by step)

This puts your site on the internet at a free public URL and makes it **update itself
every day** in the cloud — no server, no cost, your PC doesn't even need to be on.

You'll do these once. It's clicking, not coding. ~20 minutes.

## What you need
- A free **GitHub account** → https://github.com/signup
- **GitHub Desktop** (the easy, no-command-line way) → https://desktop.github.com

## Steps

### 1. Put the project on GitHub
1. Install and open **GitHub Desktop**, sign in with your GitHub account.
2. **File → Add Local Repository** → choose
   `C:\Users\Duncan-PC\Desktop\GameDealsDigest`.
3. It'll say "this isn't a git repository" → click **"create a repository"** → **Create**.
4. Click **Publish repository** (top bar).
   - **Uncheck** "Keep this code private" (Pages needs it public, and public is fine).
   - Click **Publish**.

Your code is now on GitHub. 🎉

### 2. Turn on GitHub Pages
1. On **github.com**, open your new `GameDealsDigest` repo.
2. **Settings** (top) → **Pages** (left sidebar).
3. Under **Build and deployment → Source**, choose **GitHub Actions**.

### 3. Run it
1. Go to the **Actions** tab of your repo.
2. You'll see **"Build and deploy game deals"**. Click it → **Run workflow** →
   **Run workflow** (green button). *(It also runs automatically every day.)*
3. Wait ~1 minute. When it's green, the deploy step shows your live URL — something like
   **`https://YOUR-USERNAME.github.io/GameDealsDigest/`**.

That's it — your site is **live and self-updating daily**. 🟢

## Updating it later
Any time you change a file: open **GitHub Desktop**, write a short summary, click
**Commit to main**, then **Push origin**. The site rebuilds automatically.

## Optional: a custom domain (~$12/year)
Buy a domain (Namecheap, Cloudflare) and point it at GitHub Pages (Settings → Pages →
Custom domain). Totally optional — the free `github.io` URL works fine to start.
