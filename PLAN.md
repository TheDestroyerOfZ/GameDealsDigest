# 💰 The Money Plan — honest roadmap

Goal: **prove a small automated site can earn real money, then scale the engine to a
higher-income niche.** No hype — realistic phases, costs, and timelines below.

## The honest expectations (set these now)
- **Nothing starts passive.** You do the work up front; "passive" is earned later.
- **The first milestone is your first real dollar from a stranger** — not a money
  machine. That single dollar proves the loop works. Then you scale.
- **Income is slow.** Real data: the best-documented solo directory took ~**1 year**
  of SEO ramp to meaningful traffic, and even experienced operators see ~**50% of
  sites fail**. This is a months-long game, not a weekend.
- **Cost: ~$0.** Hosting + automation are free. Optional custom domain ~$12/year.

---

## PHASE 1 — Ship the proof (this week)  →  *prove the machine works*
Get the **game deals site** live, automated, and monetised. It's already built. The
point isn't big money (gaming is a low-income niche) — it's proving the full loop:
**build → publish → auto-update → monetise → earn**, and having a real shipped product.

- [ ] **Go live** on GitHub Pages (free) — see `DEPLOY.md`. Result: a public URL.
- [ ] **Auto-update daily** via GitHub Actions (already set up in `.github/workflows/`).
- [ ] **Apply to affiliate programs**: Fanatical, Green Man Gaming, Humble. Add your
      tags to `AFFILIATE` in `config.py`.
- [ ] **Share it** in a few gaming spots (relevant subreddits, a Discord, etc.) to get
      the first trickle of visitors.
- [ ] **Watch for the first click / first affiliate signup** ← this is the proof.

**Realistic outcome:** small or no income, but a real, live, self-running, monetised
site you built — and proof the pipeline works. *Portfolio win regardless.*

---

## PHASE 2 — Build the income version (next few weeks)  →  *where the money is*
The research is clear: **software / SaaS / AI tools** pays ~10× gaming per visitor and
fits your coding credibility. Repoint the *same engine* to that niche.

- [ ] **Pick the angle**: software/SaaS **deals** aggregator, or an AI/dev **tools
      directory** (decide together — directory has a higher ceiling, ~$6k/mo for the
      winners, but needs more curation).
- [ ] **Solve the data source** (no free "CheapShark for software" exists — this needs
      design: AppSumo affiliate feed + curated listings).
- [ ] **Add a genuinely useful free tool** as the defensible hook — so Google treats it
      as real value, not thin content it penalises. *(Your coding = the moat here.)*
- [ ] **Monetise affiliate-first** (tech audiences block ads): AppSumo (100% up to
      $50/sale, verified) + SaaS programs.

**Why this and not gaming:** software visitors convert to real affiliate sales; gaming
visitors earn ad pennies and 40%+ block ads.

---

## PHASE 3 — Grow & scale (months)  →  *compound what works*
- [ ] Add content/comparisons with **real opinions + one unique fact** (survives Google).
- [ ] Basic SEO; share consistently; track what brings traffic.
- [ ] Double down on what works; add more tools/niches off the same engine.
- [ ] Accept the ~1-year ramp. Patience is the actual skill here.

---

## The one-line strategy
**Ship gaming now to prove the machine → rebuild it for software to make the money →
grow with real, defensible value Google can't kill.** Cheap to try, honest about odds,
and every phase is a portfolio asset even if the income is slow.
