# Roadmap

Possible future improvements for Game Deals Digest.

## Done
- Live deals from CheapShark (multi-store) with a quality gate + genre enrichment
- Curated highlight sections + a searchable / sortable / filterable Browse-All view
- Steam rating, review count, and Metacritic on each card
- Daily auto-build + free deployment (GitHub Actions + GitHub Pages)
- Honest disclaimers + affiliate disclosure + source attribution

## Ideas
- "Free games this week" section (Epic / Steam free-game sources)
- Price-history / "is this a good price?" indicator (e.g. IsThereAnyDeal API)
- Bundles / DLC deals, and a "newest on sale" section
- Store logos, a custom domain, an RSS feed
- Affiliate integration (Fanatical / Green Man Gaming / Humble) once approved

## Notes
- Monetisation is affiliate-first (tech audiences tend to block ads). Income from a niche
  deals site is modest and traffic-dependent — best treated as a learning / portfolio
  project.
